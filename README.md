# <img width="56" height="62" alt="image" src="https://github.com/user-attachments/assets/050d1191-696f-4d47-9342-662452457d29" /> MaterialKu
> MaterialKu merupakan aplikasi Android yang dirancang untuk membantu pengelolaan inventaris dan transaksi penjualan pada toko material bangunan secara terintegrasi. Sistem mendukung proses pengelolaan data material, pencatatan stok masuk dan keluar, transaksi penjualan (Point of Sale), pengelolaan pengguna berdasarkan hak akses, serta penyajian laporan operasional.
Aplikasi menggunakan konsep fully offline, sehingga seluruh data operasional disimpan pada database lokal menggunakan Room (SQLite). Selain itu, sistem mendukung pencetakan struk melalui thermal printer menggunakan koneksi Bluetooth Serial Port Profile (SPP) serta ekspor laporan ke dalam format PDF.
Dalam sistem MaterialKu terdapat empat jenis pengguna, yaitu Administrator, Kasir, Petugas Gudang, dan Manager. Setiap pengguna memiliki hak akses yang berbeda sesuai dengan tanggung jawabnya masing-masing. Administrator bertanggung jawab terhadap pengelolaan data master dan pengguna, Kasir mengelola transaksi penjualan, Petugas Gudang menangani mutasi stok, sedangkan Manager memanfaatkan sistem untuk memantau laporan dan kondisi operasional toko.
